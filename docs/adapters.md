# Agent Adapters

SDD Dev Kit keeps the command rules tool-neutral under `docs/sdd/commands/*`.
Adapters only help specific agents discover and follow those rules.

## Supported Adapters

| Agent | Install flag | Installed files |
| --- | --- | --- |
| Codex | `--agent codex` or `--codex` | `.codex/skills/sdd-*` |
| Claude Code | `--agent claude` | `CLAUDE.md` |
| Gemini CLI | `--agent gemini` | `GEMINI.md` |
| GitHub Copilot | `--agent copilot` | `.github/copilot-instructions.md` |
| Cursor | `--agent cursor` | `.cursor/rules/sdd.mdc` |
| Windsurf | `--agent windsurf` | `.windsurf/rules/sdd.md` |

Install all adapters:

```bash
npx sdd-dev-kit init --all-agents
```

Install selected adapters:

```bash
npx sdd-dev-kit init --agent claude --agent gemini --agent copilot
```

The legacy Codex shortcut still works:

```bash
npx sdd-dev-kit init --codex
```

## Adapter Rules

- Adapters must not become the source of truth.
- Adapters should route agents back to `AGENTS.md`, `docs/sdd/workflow.md`, and `docs/sdd/commands/*`.
- Project-specific facts must still be generated by `sdd-bootstrap` inside each target project.
