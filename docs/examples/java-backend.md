# Java Backend Example

For a Java backend, `sdd-bootstrap` should inspect:

- `pom.xml` or `build.gradle`
- application entrypoints
- controllers
- services
- repositories, mappers, or DAOs
- database migrations or SQL scripts
- configuration examples
- tests

The generated `AGENTS.md` should include project-specific rules for
authentication context, database access, configuration, messaging, caching, and
test commands when those facts are visible in the target project.
