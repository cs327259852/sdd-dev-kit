# Good First Issue Ideas

These are useful starter contributions for the project.

## Agent Adapters

- Add a Copilot instructions adapter.
- Improve the Claude adapter with command examples.
- Add more Cursor rule examples.

## CLI

- Add `sdd-dev-kit update`.
- Add `sdd-dev-kit uninstall --dry-run`.
- Improve Windows path handling.
- Add a `--dry-run` option for `init`.

## Documentation

- Add a GIF or terminal recording for the demo walkthrough.
- Add a real before/after demo project.
- Improve translations.
- Add a "Spec Kit vs SDD Dev Kit" comparison table.

## Automation

- Add a GitHub Action that checks SDD gates in a target project.
- Add tests for installed project structure.
- Add release automation for npm publishing.
