# Security Policy

## Reporting

Please do not open public issues for sensitive security problems.

Report security concerns by opening a private GitHub security advisory when available, or contact the repository owner through GitHub.

## Sensitive Data Rules

Do not submit examples, fixtures, logs, screenshots, or templates that contain:

- Passwords
- Tokens
- Private keys
- Database credentials
- Production connection strings
- Internal customer data

If a workflow needs to mention credentials, describe the mechanism without including secret values.
