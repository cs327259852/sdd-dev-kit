# Constitution

本文档是新项目的项目级工程宪法。

它不记录具体 feature 细节，也不替代模块 `current.md`。它只定义所有模块、所有 feature、所有 AI coding 任务都必须遵守的底线规则。

生成要求：

- 只写能从新项目代码、文档、配置或测试确认的事实。
- 无法确认的规则写入 Open Questions。
- 不得照搬其他项目的技术栈专属规则。
- 不得记录密码、Token、密钥、私钥、数据库凭证。

## 2. SDD 基本原则

- 修改业务行为前必须先有 feature `spec.md`。
- `spec.md` 必须经过人工确认后才能进入编码。
- 实现必须基于 `spec.md -> plan.md -> tasks.md`。
- 验证结果必须写入 feature `validate.md`。
- 如果代码行为与 SDD 文档冲突，必须停止并报告冲突。

每个 feature 至少需要说明：
